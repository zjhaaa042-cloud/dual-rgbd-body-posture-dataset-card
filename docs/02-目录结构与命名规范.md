# 02 · 目录结构与命名规范

## 1. 层级结构

```
subjects/
└── <subject_id>/
    ├── session_manifest.json
    ├── .staging/                       # 采集期临时目录，交付时为空
    └── angles/
        └── angle_<yaw>_<direction>/
            └── capture_<nn>_<UTC>/
                ├── capture_manifest.json
                ├── commit.json
                ├── camera_gemini_336l/
                │   └── <modality>/frame_<nn>.<ext>
                └── camera_realsense_d435i/
                    └── <modality>/frame_<nn>.<ext>
```

固定深度：受试者 → 视角 → 会话 → 相机 → 模态 → 帧文件（6 层）。同层目录名在整库中字符集为 ASCII。

## 2. 命名规则

| 层级 | 模式 | 说明 |
| --- | --- | --- |
| 受试者 | S + 4 位十进制序号 | 例：`S0005` 形式；本仓库不公开实际编号清单 |
| 视角目录 | `angle_%03d_%s` | 三位方位角 + 方向英文名 |
| 会话目录 | `capture_%02d_%s` | 两位尝试序号 + UTC 时间戳（ISO 8601 基本式，微秒 + Z） |
| 相机目录 | `camera_<model_slug>` | 见第 4 节映射 |
| 模态目录 | `<modality>` | 8 类，见 [03-文件格式与模态说明](03-文件格式与模态说明.md) |
| 帧文件 | `frame_%02d.<ext>` | frame_01 … frame_05 |
| 元数据 | `session_manifest.json` / `capture_manifest.json` / `commit.json` | 固定文件名 |

UTC 时间戳示例形态：`20260906T103235960681Z`（YYYYMMDDThhmmssffffffZ）。

## 3. 八个视角与方位角

方向约定：以**正面为 0°**，俯视**顺时针**递增 45°。

| 目录名 | yaw_deg | 方向 | 含义 |
| --- | --- | --- | --- |
| angle_000_front | 0 | front | 正面 |
| angle_045_front_right | 45 | front_right | 右前 |
| angle_090_right | 90 | right | 右侧 |
| angle_135_back_right | 135 | back_right | 右后 |
| angle_180_back | 180 | back | 背面 |
| angle_225_back_left | 225 | back_left | 左后 |
| angle_270_left | 270 | left | 左侧 |
| angle_315_front_left | 315 | front_left | 左前 |

每个受试者的 8 个视角**全部存在**（83/83），每个视角恰好 1 次成功尝试，无重采目录。

## 4. 相机目录与代号映射

| 目录名 | camera_code | 型号 | 角色 |
| --- | --- | --- | --- |
| camera_gemini_336l | C336L | Orbbec Gemini 336L | 主视角，要求完整人体入画（full_body_required） |
| camera_realsense_d435i | CD435I | Intel RealSense D435I | 辅助视角，视场受限不阻塞（auxiliary_fov_limited_non_blocking） |

同一会话内两台相机各自有 5 帧，按 frame_01…frame_05 一一对应配对。

## 5. 目录空间占用参考

- 受试者目录：657 个文件，≈ 509 MiB
- 视角目录：82 个文件（80 数据 + 2 清单），≈ 63 MiB
- 模态目录：5 个文件（frame_01 … frame_05）
