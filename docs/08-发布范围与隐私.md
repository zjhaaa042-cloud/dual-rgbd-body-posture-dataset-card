# 08 · 发布范围与隐私

## 1. 本仓库发布什么

| 发布 | 内容 |
| --- | --- |
| ✅ | 数据目录结构、命名规范、字段字典 |
| ✅ | 文件格式、位深、形状、单位与语义 |
| ✅ | 聚合规模统计（文件数、容量、完整度）与质量指标分布 |
| ✅ | 同步机制、时间偏差分布、标定口径与陷阱说明 |
| ✅ | 读取方式与使用注意事项 |

## 2. 本仓库不发布什么

| 不发布 | 原因 |
| --- | --- |
| ❌ 原始 RGB / 深度 / 点云文件 | 含受试者体貌信息 |
| ❌ 伪彩预览图 | 同上，且易于视觉识别 |
| ❌ 人体测量数值（m1/m2/final_value 等） | 个人体质数据 |
| ❌ 受试者编号的实际清单、起止范围与逐人对应关系 | 可与其他数据交叉重识别（如需公开编号段，由数据持有方决定） |
| ❌ 设备序列号、UID、唯一标识 | 设备指纹 |
| ❌ output_directory / output_root 等本机绝对路径 | 暴露采集环境 |
| ❌ 逐会话的 UTC 采集时间戳与逐会话偏差明细 | 弱标识，可缩小定位范围 |
| ❌ 三份 JSON 清单原文 | 上述敏感字段的载体 |

## 3. 已确认的敏感字段位置（供数据持有方自查）

若数据持有方对外提供原始清单，建议至少剔除或哈希化以下字段：

| 文件 | 字段 |
| --- | --- |
| session_manifest.json | output_directory、output_root、anthropometry.records[].m1 / m2 / final_value、subject_id |
| capture_manifest.json | frames[].camera_metadata.device.serial_number / uid / id、attempt_id、captured_at |
| commit.json | subject_id、attempt_id、committed_at |

本仓库的 .gitignore 已屏蔽 subjects/ 目录、三份清单文件名与常见数据文件类型，避免误提交。

## 4. 若需要发布示意素材

确有必要展示效果时，建议：

- 只发布**点云/骨架等无纹理渲染**，不使用彩色贴图；
- 裁掉背景与可识别的环境特征；
- 避免人脸区域，必要时做模糊或裁切；
- 单张素材不附带受试者编号与时间戳。

## 5. 使用合规提示

数据仅用于研究与算法验证。使用前请确认符合所在机构的伦理审查与数据合规要求，不得用于个体识别；再分发遵循 [LICENSE](../LICENSE)（MIT）。
