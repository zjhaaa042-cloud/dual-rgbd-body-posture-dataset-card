# 07 · 读取与使用指南

## 1. 建议的读取顺序

1. 读受试者级清单 session_manifest.json：确认 8 个视角齐备、拿到每个视角的会话路径与清单哈希。
2. 读会话清单 capture_manifest.json：看 sync_audit（双机时间关系）、metadata.distance_mm、frames[] 的内参与深度比例。
3. 按 files[] 校验文件（size_bytes + sha256），确认数据完整。
4. 再按需读取具体模态文件。

## 2. 深度读取与毫米换算

```python
import json
import numpy as np
import cv2

cap = "subjects/<subject_id>/angles/angle_000_front/capture_01_<UTC>"
manifest = json.load(open(f"{cap}/capture_manifest.json", encoding="utf-8"))

cam = "C336L"
frame_idx = 0                       # 0..4 对应 frame_01..frame_05
scale = manifest["frames"][cam][frame_idx]["depth_scale_mm_per_unit"]

# 方式一：无损 uint16 PNG（必须保留原始位深）
png = cv2.imread(f"{cap}/camera_gemini_336l/depth_raw_uint16/frame_01.png",
                 cv2.IMREAD_UNCHANGED)
assert png.dtype == np.uint16, png.dtype

# 方式二：等值 NumPy 数组（mmap，不预乘比例）
npy = np.load(f"{cap}/camera_gemini_336l/depth_raw_npy/frame_01.npy", mmap_mode="r")

assert np.array_equal(png, npy)     # 两者逐像素一致

depth_mm = npy.astype(np.float32) * scale
depth_mm[npy == 0] = np.nan         # 0 = 无效
```

## 3. 彩色与点云

```python
# 彩色：RGB 顺序，需按需转 BGR
rgb = cv2.cvtColor(cv2.imread(".../rgb_color/frame_01.png"), cv2.COLOR_BGR2RGB)

# 点云：binary_little_endian PLY，x/y/z float32 + rgb uint8，单位毫米
import open3d as o3d
pcd = o3d.io.read_point_cloud(".../pointcloud_color_xyz_mm/frame_01.ply")
```

点云也可用 plyfile / 手工解析头部的 `end_header` 之后按 15 字节/顶点读取（3×float32 + 3×uint8）。

## 4. 双机融合前的检查清单

- [ ] 读取本会话 sync_audit.max_host_timestamp_skew_ms，确认在可接受范围内（全库 9.00–73.86 ms）。
- [ ] 需要逐对时间戳时使用 sync_audit.pairs[]，用 host_timestamp_ns 做插值/最近邻配对。
- [ ] 统一外参平移单位（C336L 为毫米、CD435I 为米）。
- [ ] 统一深度单位后再做点云拼接（逐帧 depth_scale_mm_per_unit，不要硬编码）。
- [ ] 去畸变按各自 distortion_model 与系数长度处理，不要混用实现。

## 5. 常见陷阱

| 陷阱 | 说明 |
| --- | --- |
| 8 位读取深度 | 16 位 PNG 若用默认方式读取会被截断，必须指定保留原始位深 |
| 假设统一分辨率 | C336L 原始深度 848×480，彩色/对齐深度 1280×720；CD435I 三者同为 1280×720 |
| 把伪彩当深度 | depth_*_color 是 8 位伪彩预览，无量化语义 |
| 忘记乘深度比例 | NPY/PNG 都不预乘比例；CD435I 的比例并非精确 1.0 |
| 把 0 当 0 毫米 | 0 表示无有效深度，需掩掉 |
| 外参单位不一致 | C336L 毫米、CD435I 米 |
| 期望红外模态 | C336L 不提供 IR，缺失模态不会被伪造 |
| 把 CD435I 当主视角 | 其视场受限（auxiliary_fov_limited_non_blocking），人体可能不完整，宜作辅助 |
| 假设硬件同步 | 双机为主机时钟近同步，快速运动场景需显式时间对齐 |
| 硬编码字段存在性 | files[] 中 `depth_scale_mm_per_unit`、`logical_modality`、色彩相关字段仅出现在特定模态 |
