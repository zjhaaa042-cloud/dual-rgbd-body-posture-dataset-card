# 04 · 元数据字段字典

本页给出三份 JSON 清单的**字段结构、类型与取值域**。所有清单中出现的具体数值（含受试者人体测量值、设备序列号、本机路径）均不在本仓库发布范围内，见 [08-发布范围与隐私](08-发布范围与隐私.md)。

## 1. session_manifest.json（受试者级，每人 1 份）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| schema_version | string | 受试者清单版本，固定 `dual-rgbd-v2.2` |
| layout_version | string | 目录布局版本，固定 `readable-v1` |
| storage_features | string[] | 启用的存储特性 |
| subject_id | string | 受试者编号（S + 4 位序号） |
| status | string | 受试者级状态，取值见 §4 |
| created_at / completed_at | string | 建档 / 完成时间（UTC，带时区偏移） |
| output_directory / output_root | string | 采集端输出路径（**不发布**） |
| clothing_note | string | 着装备注（全库为空串） |
| target_distance_mm | number | 该受试者的目标拍摄距离（毫米） |
| angles | object | 以视角键（V000、V045 … V315）为键的进度对象 |
| anthropometry | object | 人体测量记录与 QC 结果 |
| integrity | object | 完整性检查结果 |
| reconciliation_required | boolean | 是否需要重建核对 |
| recovery_report | object \| null | 异常恢复报告 |
| completion | object | 完成判定 |

### 1.1 angles.<Vxxx>

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| yaw_deg | number | 该视角方位角（0/45/…/315） |
| status | string | 视角状态，取值 `CAPTURED` |
| attempts | array | 该视角的采集尝试列表 |

attempts[] 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| attempt_id | string | 尝试标识，等同会话目录名 `capture_<nn>_<UTC>` |
| path | string | 相对路径 angles/angle_xxx_yyy/capture_... |
| captured_at | string | 采集时刻（UTC） |
| capture_manifest_sha256 | string | 该会话 capture_manifest.json 的整体 SHA-256（防篡改锚点） |
| max_host_timestamp_skew_ms | number | 该会话双机最大主机时间戳偏差（毫秒） |

### 1.2 anthropometry

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| status / complete | string / boolean | 测量完成状态 |
| saved_at | string | 测量保存时间 |
| policy_version | string | 规约版本，固定 `five-measurement-qc-v1` |
| records | array | 逐测量项记录（5 项） |
| missing_required / review_required | string[] | 缺失必填项 / 待复核项（全库均为空） |

records[] 元素：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| measurement_id | string | 测量项编号，如 M01 |
| field_name | string | 测量项字段名（见 §4 五项） |
| m1 / m2 | number | 第 1、2 次读数（**数值不发布**） |
| first_two_difference | number | 前两次读数之差 |
| third_measurement_threshold | number | 触发第 3 次读数的阈值（厘米） |
| third_measurement_required | boolean | 是否需要第 3 次读数 |
| selected_trial_indices | number[] | 最终采信的读数序号 |
| selected_difference / closest_pair_difference | number | 采信读数差 / 最接近两读数的差 |
| reduction_rule | string | 收敛规则，见 §4 |
| final_value | number | 最终取值（**数值不发布**） |
| qc_status | string | 该项 QC 结论，见 §4 |

### 1.3 integrity / completion

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| integrity.status | string | `OK` 表示完整性检查通过 |
| integrity.errors | string[] | 错误列表（全库为空） |
| integrity.checked_at | string | 检查时间 |
| completion.can_complete / completed | boolean | 是否可完成 / 是否已完成 |
| completion.completed_at / status | string | 完成时间与状态 |
| completion.blockers | string[] | 阻塞项（全库为空） |

## 2. capture_manifest.json（会话级，每会话 1 份）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| schema_version | string | `dual-capture-v1.1` |
| storage_features | string[] | 启用的存储特性 |
| attempt_id / subject_id / group_id | string | 会话标识 / 受试者 / 视角键 |
| yaw_deg / angle_name | number / string | 方位角与方向名 |
| captured_at | string | 采集时刻（UTC） |
| cameras | string[] | 相机代号列表（`["C336L","CD435I"]`） |
| frames | object | 按相机代号分组的逐帧记录（每相机 5 条） |
| metadata | object | 采集条件 |
| sync_audit | object | 时间同步审计 |
| pointcloud | object | 点云格式约定 |
| files | array | 该会话全部文件清单（80 条）与逐文件 SHA-256 |

### 2.1 frames.<camera_code>[i]

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| frame_index | number | 帧序号 1–5 |
| host_timestamp_ns | number | 主机接收时间戳（纳秒） |
| device_timestamp | number | 设备时间戳（单位由 timestamp_unit 决定） |
| frame_number | number | 设备帧计数 |
| depth_scale_mm_per_unit | number | 该帧深度值 → 毫米的比例 |
| stream_timestamps | object | 各流时间戳（color / depth_raw / depth_aligned） |
| stream_frame_numbers | object | 各流帧计数 |
| intrinsics | object | 三套内参：color、depth_raw、depth_aligned |
| extrinsics | object | 外参：depth_raw_to_color（CD435I 另有 color_to_depth_raw） |
| camera_metadata | object | 设备信息、码流配置、运行时控制、帧契约 |

内参条目字段：fx、fy、cx、cy、width、height、distortion_model、coefficients[]。
外参条目字段：source、target、rotation[9]、translation[3]、translation_unit。

### 2.2 metadata / sync_audit / pointcloud

| 字段 | 说明 |
| --- | --- |
| metadata.distance_mm | 本次采集的实际拍摄距离（毫米） |
| metadata.ready_confirmed_at | 采集就绪确认时刻 |
| metadata.framing_policy | 各相机取景策略（C336L / CD435I 键） |
| sync_audit.synchronization_kind | 同步方式，固定 `host_clock_near_sync` |
| sync_audit.pair_count | 配对帧数（恒为 5） |
| sync_audit.max_host_timestamp_skew_ms | 本会话最大主机时间戳偏差（毫秒） |
| sync_audit.pairs[] | 逐对记录：request_start_skew_ms、host_timestamp_skew_ms、两台相机的主机与设备时间戳、帧计数 |
| pointcloud.format | 固定 `binary_little_endian_ply` |
| pointcloud.coordinate_unit | 固定 `millimeter` |
| pointcloud.color_order | 固定 `RGB` |
| pointcloud.pixel_stride | 固定 4（每 4 像素取 1 点） |

### 2.3 files[]

按模态不同，字段集合略有差异：

| 字段 | 出现的模态 | 说明 |
| --- | --- | --- |
| camera_code / camera_name | 全部 | 相机代号与型号名 |
| frame | 全部 | frame_01 … frame_05 |
| modality | 全部 | 模态键（8 类） |
| logical_modality | 仅 *_npy | 归并到 depth_raw / depth_aligned |
| modality_name | 全部 | 中文模态名 |
| path | 全部 | 相对会话目录的路径 |
| format / dtype / shape | 除点云外 | 格式、数据类型、形状 |
| order / allow_pickle | 仅 *.npy | C 序 / 禁止 pickle |
| size_bytes / sha256 | 全部 | 文件字节数与内容哈希 |
| depth_scale_mm_per_unit / value_semantics | 仅 *_npy | 深度比例与数值语义 |
| array_channel_order / file_color_space / png_decoder_channel_order | 仅 rgb_color | 通道序 / 文件色彩空间 / 解码器通道序说明 |

## 3. commit.json（会话级提交记录，每会话 1 份）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| schema_version | string | `dual-commit-v1.0` |
| status | string | `COMMITTED` |
| attempt_id / subject_id / group_id / yaw_deg | — | 与会话清单同源 |
| committed_at | string | 提交时刻（UTC） |
| capture_manifest | object | 被提交清单的路径与 SHA-256 |
| file_count | number | 文件数（恒为 80） |
| files[] | array | 与 capture_manifest.files 同构的文件清单副本 |

commit.json 的意义是**双写锚定**：清单自身哈希进入受试者级清单，文件清单再独立落一份提交记录，任一处被改动都可被发现。
