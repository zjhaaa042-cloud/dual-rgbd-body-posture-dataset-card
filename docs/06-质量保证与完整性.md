# 06 · 质量保证与完整性

## 1. 校验链（三层锚定）

| 层级 | 内容 | 作用 |
| --- | --- | --- |
| 文件级 | capture_manifest.json 的 files[] 记录每个文件的 SHA-256 与字节数 | 逐文件内容校验 |
| 清单级 | 受试者清单 angles.<Vxxx>.attempts[].capture_manifest_sha256 记录会话清单自身哈希 | 防止清单被替换 |
| 提交级 | 每个会话另有一份 commit.json（status = COMMITTED），内含 capture_manifest 哈希与完整文件清单副本 | 双写交叉验证 |

配套存储特性（storage_features）：

| 特性 | 含义 |
| --- | --- |
| depth_npy_uint16_v1 | 深度以无损 uint16 提供 PNG 与等值 NumPy 数组两份 |
| per_frame_calibration_v1 | 内外参随帧落盘，不依赖全局标定文件 |
| durable_commit_v1 | 会话级提交记录，落盘即锚定 |

## 3. 采集准入控制

会话在采集前/采集时即写入以下判据，可回溯“为什么这一帧可用”：

| 字段 | 位置 | 说明 |
| --- | --- | --- |
| metadata.ready_confirmed_at | 会话清单 | 受试者与机位就绪的确认时刻 |
| metadata.framing_policy | 会话清单 | C336L 要求完整人体入画；CD435I 视场受限但不阻塞流程 |
| metadata.distance_mm | 会话清单 | 实际拍摄距离（毫米） |
| camera_metadata.device.stream_preflight | 会话清单 | 设备码流预检（所需模态齐全、超时阈值） |
| camera_metadata.temporal_alignment.maximum_allowed_ms | 帧契约 | 单机内三流时间戳偏差上限 |
| camera_metadata.runtime_controls | 会话清单 | 曝光/增益/激光等运行时控制量及其读取状态 |

## 4. 人体测量质量控制（five-measurement-qc-v1）

策略：对每个测量项最多采 3 次读数，用“前两次差异 + 阈值”决定是否需要第 3 次。

| 规则 | 说明 |
| --- | --- |
| third_measurement_threshold | 前两次读数差超过该阈值（厘米）时触发第 3 次 |
| qc_status = PASS_2 | 前两次读数已收敛，采信 2 次 |
| qc_status = PASS_3 | 需要并完成第 3 次读数 |
| reduction_rule = MEAN_FIRST_TWO | 默认：取前两次读数均值 |
| reduction_rule = MEAN_CLOSEST_PAIR | 三次读数中取最接近一对的均值 |

测量项（5 项，每人齐全）：

| measurement_id | field_name | 语义 |
| --- | --- | --- |
| M01 | height_cm | 身高（厘米） |
| M02 | biacromial_breadth_cm | 肩宽（厘米） |
| M03 | nipple_chest_circumference_cm | 胸围（厘米） |
| M04 | midpoint_waist_circumference_cm | 腰围（厘米） |
| M05 | max_hip_circumference_cm | 臀围（厘米） |
